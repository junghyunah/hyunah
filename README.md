# 👴👵 노인일자리 참여자 관리도구 (Senior Job Manager)

> **노인복지관 실무 담당자를 위한 직관적이고 감각적인 참여자·근무지·활동중지 통합 웹 관리도구**  
> 공원환경개선, 지역사회환경개선, 맞춤돌봄(맞돌) 사업단의 참여자 명단, 근무지 T.O, 다회 활동중지 일수 자동 계산, 수요처 모니터링을 한눈에 관리할 수 있습니다.

---

## 📌 1. 프로젝트 개요

- **사용 대상:** 노인복지관 노인일자리 사업 전담 담당자
- **운영 환경:** 노트북 및 복지관 업무용 PC 웹브라우저 (단일 HTML 실행, 설치 불필요)
- **개인정보 보호 원칙:** 주민등록번호 미수집 (`이름 + 생년월일`로 동명이인 구분), 로컬 브라우저 영속 저장(LocalStorage)

---

| 사업단 | 시그니처 색상 | 활동중지 연간 한도 | 비주얼 상징 |

## 🚀 3. 핵심 기능 안내

### ① 사업단별 참여자 명단 & 근무지별 T.O 비교
- **근무지별 묶음 표시**: 근무지별 목표 정원(T.O) 대비 현재 참여 인원 및 부족 인원을 실시간 계산하여 표시합니다.
- **대기자 전용 관리**: 근무지가 미배정된 선발 전 신청자는 별도 대기자 구역에서 관리하며, 선발 시 원클릭 `[참여 전환]`을 통해 근무지와 활동 시작일을 즉시 배정합니다.
- **🚨 확인 필요 (기간 임박)**: 활동중지자 중 종료 예정일이 경과했거나 복귀가 임박한 대상자를 감지하여 눈에 띄는 뱃지로 안내합니다.

### ② 활동중지 다회 관리 및 일수 자동 계산
- **다회 등록 및 이력 추적**: 참여자 1인당 발생하는 여러 건의 활동중지 기간을 자유롭게 등록·수정·삭제합니다.
- **정확한 일수 계산**: 시작일과 종료일을 모두 포함(양 끝일 포함, inclusive)하며, 주말과 공휴일을 포함하여 일수를 자동 합산합니다.
- **한도 초과 및 기간 중복 검증**: 사업단별 한도(45일/30일) 초과 시 경고 배너를 띄우며, 기존 중지 기간과의 날짜 겹침을 사전에 방지합니다.
- **수동 복귀 확인**: 종료일이 지나도 자동으로 참여로 전환되지 않으며, 담당자가 실제 복귀일을 확인한 후 전환하도록 설계되었습니다.

### ③ 수요처 관리 & 사업단 필터링 연동
- 수요처 등록 시 사업단(`공원환경개선`, `지역사회환경개선`, `맞돌`, `공통`)을 지정할 수 있습니다.
- 상단 사업단 알약 탭을 누르면 해당 사업단의 수요처만 즉시 필터링됩니다.
- 관리 면적, 담당자명, 담당자 휴무일(모니터링 참고용), 연락처, 메모를 함께 관리합니다.

### ④ 중도포기자 영구 보존 보관함
- 중도포기 발생 시 실제 포기일자와 사유를 필수로 기록하며, 기존 활동 이력은 삭제되지 않고 `[중도포기자 보관함]` 탭에 영구 보존됩니다.

### ⑤ 엑셀(`.xlsx`) 일괄 가져오기
- SheetJS 라이브러리를 탑재하여 브라우저에서 엑셀 파일을 드래그 앤 드롭으로 즉시 분석합니다.
- 필수값 누락, 날짜 형식 오류를 자동 감지하고, 동일 연도·사업단 내 `이름 + 생년월일` 중복 후보를 사전에 안내합니다.
- 실무 담당자를 위한 **샘플 엑셀 서식 다운로드** 기능 제공.

### ⑥ 데이터 백업 & 2대 PC(노트북/복지관 PC) 동기화
- 브라우저 로컬 저장소(LocalStorage)에 안전하게 자동 저장되어 새로고침해도 데이터가 보존됩니다.
- 노트북과 복지관 PC 간 이동을 위해 **전체 데이터 JSON 내보내기/불러오기(백업 및 복원)** 기능을 지원합니다.

## 🖥️ 4. 실행 방법

별도의 서버 설치나 빌드 과정 없이, 브라우저만 있으면 즉시 실행할 수 있습니다.

1. 저장소를 클론(Clone)하거나 다운로드합니다:
   ```bash
   git clone https://github.com/junghyunah/hyunah.git
   ```
2. 다운로드된 폴더 내의 [`index.html`](index.html) 파일을 더블 클릭하여 크롬(Chrome) 또는 엣지(Edge) 브라우저에서 엽니다.
3. 기본 적재된 가상 예시 데이터를 바탕으로 모든 기능을 즉시 테스트해볼 수 있습니다.
